## Commands To Upload On GitHub

### 1. Initialize Git

```bash
git init
```

### 2. Add Files

```bash
git add .
```

### 3. Commit Files

```bash
git commit -m "Initial commit"
```

### 4. Connect GitHub Repository

```bash
git remote add origin YOUR_REPOSITORY_LINK
```

### 5. Push Code

```bash
git branch -M main
git push -u origin main
```
